# 下班提醒助手 (Work-Off Reminder for Windows)

一款专为 Windows 用户打造的优雅、超低资源消耗的下班全屏提醒与桌面倒计时挂件软件。

---

## 核心特性

1. **极低性能占用（CPU 接近 0%，超小内存）**
   - 核心调度引擎采用事件驱动模型，后台待机仅进行轻量毫秒级对齐判断，绝无轮询死循环。
   - 全屏提醒窗口在未触发时完全不占用 GPU 与重绘显存。
   - 托盘与桌宠常驻守护，轻量极速。

2. **桌面下班倒计时挂件（桌宠模式）**
   - 纯矢量绘制的萌趣小猫猫挂件头像（眨眼交互，无外部图片依赖，高清防抖）。
   - 实时大字号下班倒计时（格式：时:分:秒）。
   - 下班进度条：直观展示今日工时完成百分比。
   - 鼠标悬停贴心提示：根据当前时间动态展示工作打气小语。
   - 支持按住鼠标左键任意拖拽移动位置，松开自动记忆屏幕坐标。
   - 挂件右键快捷菜单：支持锁定位置（防误触拖动）、始终置顶、隐藏挂件、打开设置、全屏测试。

3. **简洁现代的高质感全屏视觉与平滑过渡动画**
   - 全屏毛玻璃/微磨砂质感卡片设计，现代阴影投影与精美排版。
   - 独立解耦的淡入（Fade-In）与淡出（Fade-Out）硬件加速动画。
   - 居中展示实时高精度大数字时钟（跳秒动态刷新）。
   - 支持快捷键 Esc 键、右上角关闭按钮或主按钮平滑退出。

4. **丰富的自定义样式**
   - 文字定制：主标题标语、副标题/温馨备忘文案。
   - 排版控制：支持字体家族（微软雅黑、Segoe UI、黑体等）、主/副标题字号、文本颜色与时钟颜色。
   - 多样化背景模式：
     - 沉浸暗黑磨砂风（推荐，商务极简）
     - 绚丽渐变色彩（内置落日余晖、极光梦境、午夜星空、蔚蓝深海、薰衣草幻境等预设）
     - 纯色背景（自由调色板）
     - 自定义本地壁纸大图（支持选择本地 JPG/PNG/WebP 图片，并提供遮罩浓度调节）。
   - 挂件调节：支持设置中自定义桌宠挂件不透明度与开关。

5. **灵活的提醒时间与工作日筛选**
   - 支持多提醒时间点（如添加 17:55 提前准备工位，18:00 准时打卡下班）。
   - 支持周一至周日独立勾选，支持一键切换工作日、全天候、周末等。
   - 提供“立即全屏预览测试”按钮，调整完外观可瞬间体验实际效果。

6. **系统托盘管理与开机自启动**
   - 系统托盘动态图标，鼠标悬浮即时显示下次下班提醒时间。
   - 右键托盘快捷菜单：打开设置、测试弹窗、显示/隐藏挂件、临时暂停/恢复、开机自启开关、退出程序。
   - 采用 Windows 注册表免管理员权限自启动，开机静默后台运行。
   - 内置单实例互斥机制，重复启动时自动激活已运行实例的设置界面。

## 项目结构

```
下班提醒/
├── 下班提醒.exe              # 独立便携可执行程序（无依赖，双击直接运行）
├── icon.ico                 # 程序图标
├── main.py                  # 源码主程序入口
├── run.bat                  # 脚本启动批处理
├── config.json              # 用户配置持久化文件（运行后自动生成）
├── README.md                # 软件说明文档
└── app/                     # 模块化源码
    ├── config.py            # 配置管理模块
    ├── autostart.py         # 开机自启动注册表管理
    ├── scheduler.py         # 低功耗秒级调度与倒计时计算引擎
    └── ui/
        ├── assets.py        # 图标与渐变色彩预设
        ├── pet.py           # 桌面下班倒计时挂件（桌宠）
        ├── popup.py         # 全屏动画弹窗
        ├── settings.py      # 图形化设置面板
        └── tray.py          # 系统托盘与交互管理
```

## 启动与使用方法

### 方式 1：双击运行 EXE（最推荐）
直接双击运行项目根目录下的 **`下班提醒.exe`**：
- 完全免 Python 环境依赖，直接在任意 Windows 10/11 电脑上双击即可运行。
- 启动后，桌面上将常驻显示“下班倒计时挂件”，同时右下角系统托盘显示图标。
- 可以将 `下班提醒.exe` 发送到桌面快捷方式，或者复制到任意文件夹使用。

### 方式 2：Python 脚本运行（开发者模式）
双击 `run.bat` 或在终端运行：
```bash
python main.py
```

---

### 快捷操作指南：
- **移动挂件**：按住鼠标左键拖拽挂件到桌面任意位置，松开即自动记忆。
- **挂件菜单**：在挂件上点击鼠标右键，可选择锁定位置、始终置顶、隐藏挂件、打开设置等。
- **打开设置**：双击桌面挂件或右下角托盘图标，均可呼出设置面板。
- **开机自启**：在设置面板或托盘右键菜单中勾选“开机自启动”即可。
